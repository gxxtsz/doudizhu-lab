# 记录、回放与纠错

使用scrcpy-server 5.0.1只读视频通道，无音频、控制和剪贴板。ADB点击由独立输入闸门管理。默认2400×1080、视频上限15 FPS、8 Mbps，牌桌分析上限10 FPS。

“开始连续游戏”自动准备临时录像和会话，无需另点记录按钮。视频接收、MKV写盘、只读前台检查和监控由独立进程负责，主程序通过有界通道取得分析副本；分析消费落后时等待关键帧重新同步，完整录像不因此丢包。自动跟踪按关键帧每约三十秒分段，显式`--record`和正式`--acceptance`仍完整保存、每约两分钟分段。

这里的“正常完成”表示程序从开局正常跟踪到结算，与输赢无关。正常局、用户主动停止或暂停的未完成局清理临时录像；已发生程序异常的录像不会因之后手动停止而被删除。大厅、匹配、叫抢和局间切换也属于临时录制窗口，开局前卡住仍会保留资料。清理只处理已关闭且不被当前窗口或故障窗口使用的片段，故障录像可能带有少量相邻正常画面作为解码上下文。

“停止任务”在后台完成收尾，期间不能打开回放。无异常的自动会话在截图线程、录像进程及数据库都关闭后，清理录像、截图和会话快照，运行摘要保存在`data/recording-summaries`，任务账本保留。仅存在可回放媒体时显示“查看本次回放”；顶部“录像回放”过滤无媒体的会话。回放支持播放暂停、拖动进度、逐帧查看，双击事件或疑点定位。

## 卡住检测与故障资料

主程序每秒报告健康状态。界面心跳三秒未更新，或已正常输出的处理阶段存在在途工作但三秒未完成，会触发异常；首次输出允许二十秒预热。识别队列的等待有超时，后帧不会越过尚未完成的前帧。正常等待其他玩家不属于处理阻塞；未知页面、匹配和结算等待继续使用现有流程超时规则。

发生异常后立即停止自动操作；采集仍可运行时最多尾录十秒。独立进程保存故障时间、最近状态及健康信息，主程序可响应时补充截图和线程堆栈；预置的原生超时转储可在主界面阻塞时留下堆栈。采集中断、磁盘不足或进程被强制结束时，只保留实际取得的片段，不声明录像完整。

SQLite保存原始观察、确认事件、疑点、机器人意图和人工修订；`留存记录.json`保存窗口处置及按策略清理的媒体范围，`故障诊断.json`和`线程堆栈.txt`用于排查阻塞。异常资料仍包含同版程序、配置、模板和模型快照。无明确结束决定的资料按异常保留；清理失败会报告文件占用或路径错误，不伪装成已清理。

日常跟踪完成与正式录像验收分开报告。已按策略清理的媒体不算真实采集缺口，也不能用于证明完整录像验收通过；正式验收需显式保留完整录像和独立标注。

## 整包清理旧会话

工具默认只生成精确清单；显式执行原清单时，删除其中已结束的会话及明确关联的任务目录。运行中的资料、越界路径、符号链接和Windows目录联接会被拒绝，全局配置、模板、标定和模型保留。先通过`ddz-check stop-run 会话对应的任务目录 --close-window`正常停止当前任务，再生成并执行清单：

```powershell
uv run python tools/clean_legacy_recordings.py --data-dir .\data --manifest .\data\migration\旧录像清理清单.json
uv run python tools/clean_legacy_recordings.py --data-dir .\data --manifest .\data\migration\旧录像清理清单.json --apply
```

清单记录已删除路径、文件大小、磁盘空间变化、清理错误和受保护资料指纹；重复执行不会删除后来新建的会话。

## 回放与纠错

“修正事件”修改选中事件；“更多纠错”提供插入事件、撤销选中事件及撤销最近修订。纠错追加修订，关闭重开后仍生效，不覆盖原始观察。修改牌局边界不会移除真实采集缺口。回放不持有手机控制入口。

回放界面移除模板采集、标定、人工标注和重算工具。独立标注格式、纠错批次与离线重算底层能力保持兼容，命令行示例如下：

```powershell
uv run ddz-check audit-video .\data\sessions\示例会话
uv run ddz-check reanalyze .\data\sessions\示例会话
uv run ddz-check evaluate-session .\data\sessions\示例会话 --labels .\独立标注.json --require-pass
```

重算生成独立版本，不覆盖实时记录；自动、离线和人工修订分别报告。未完成的事件识别验收不能用流程运行或模型合法建议代替。

## 源码快照

源码运行和wheel安装后均会保存同版程序、`uv.lock`、工程元数据和许可证。快照使用文件哈希核验，读取时不执行其中代码。

留存的旧会话及旧快照保持原内容，可通过显式目录打开；显式清理的会话无法恢复。原机器上的历史资料不随新项目复制；旧快照保留旧内部包路径，必须使用其自身的锁定工程才能重现当时算法。新版重新分析的结果不能冒充旧版实时结果。

回放建议评测必须显式给出预先选定的范围：

```powershell
uv run ddz-check evaluate-bot --mode replay --session .\数据\示例会话 --scope .\范围.json --require-pass
```

格式见[合成范围示例](../examples/replay-scope.example.json)。范围只用于选局，不向模型提供事件答案、隐藏手牌或未来信息。
