# 配置与数据

数据目录依次选择：

1. 显式`--data-dir`参数。
2. `DDZ_DATA_DIR`环境变量。
3. 从源码运行时的工程`data`目录。
4. 安装版的`%LOCALAPPDATA%\DoudizhuLab`。

不根据终端当前目录猜测工程，也不将运行资料写入`site-packages`。其他平台存在XDG路径退路，但目前只声明Windows支持。

```powershell
uv run ddz-lab --data-dir .\data
uv run ddz-check --data-dir .\data devices
```

ADB路径以调用者明确指定和保存的配置为准；未配置时读取`ADB_PATH`，再查找PATH。没有作者电脑固定盘符依赖。所有设备命令必须指定序列号。

## 本机目录

| 目录／文件 | 用途 | 提交到Git |
| --- | --- | --- |
| `settings.json` | 第七版配置与当前标定 | 否 |
| `templates`、`markers`、`controls` | 牌点、标记和按钮模板 | 否 |
| `models`、`tools` | 已校验权重与视频服务器 | 否 |
| `sessions`、`runs` | 录像、观察、修订和任务账本 | 否 |
| `migration` | 本机迁移和验证记录 | 否 |

旧配置读取时补齐默认值，不自动回写；首次保存升级为第七版并保留`settings.v原版本.bak.json`，已有备份不覆盖。第七版`profile.continuous_settings`只保存`max_games`，须为正整数且不设上限；旧版`time_limit`读取时仅在内存移除，原目标局数保留，历史会话和故障资料不回写。原有字段与SQLite记录保持兼容；`profile.play_model`支持`resnet`、`wp`，缺少时默认ResNet。示例配置不含真实设备路径或可执行的按钮标定。

启动自动后台加载所选本地模型，默认ResNet，唯一授权设备自动只读预览；加载和预览本身不授予自动输入。运行授权、动作和连续执行状态不跨重启保存。新配置默认严格模式、固定不叫不抢、始终不加倍、最多5局，不限制任务总时长；已有配置保留已保存的偏好。

“设置”管理目标设备、刷新设备、ADB路径、出牌模型、连续策略、叫抢策略、统一叫抢阈值及最多局数，场次下拉框和“最长时间”已移除，工作台统一显示“沿用当前页面”。最多局数使用数字文本输入，不受Qt整数范围限制，保存后用于下一次任务；面板只展示已用时间。准备、录制、暂停和保存期间相关字段只读。取消不改变配置，保存失败保留原值。空闲时保存新的模型选择会后台串行卸载旧模型、加载新模型；旧建议失效，加载期间不能开始任务。不清除已有模板、区域或按钮标定。表单可滚动，保存和关闭按钮固定可见。

选择“模型自动叫抢”后可编辑“叫抢阈值”，首叫、首次抢地主和回抢共用输入的数值；选择“固定不叫不抢”时输入框禁用，切换策略保留待保存文本。新配置或缺少整个叫抢配置时，三个阈值均默认设为`0.5`，默认策略仍为固定不叫不抢。允许`[-10, 10]`内的有限数值，支持小数及科学计数法，不主动舍入；评分严格高于阈值才叫抢，相等时拒绝。阈值越低越积极，数值为模型原始评分，不是胜率。空值、非数字、非有限值和超范围输入显示中文错误，不保存改动。

已有三个阈值相同时回显该值；不同时，统一输入框留空，并显示当前首叫、首次抢和回抢数值，此时留空保存会保留原来的三项设置。显式填写统一值后，保存时同时写入`profile.bid_settings`的`call_threshold`、`rob_threshold`、`reclaim_threshold`，下一次任务生效；不新增配置字段，仍使用第七版格式。旧分阶段配置继续要求阈值满足“首叫 ≤ 首次抢 ≤ 回抢”。

`--max-games`仅覆盖本次任务局数，不自动保存；旧`--time-limit`隐藏并忽略，提供该参数时提示一次弃用。任务只按目标局数正常完成，主动停止、异常留证及各阶段超时继续生效；稳定性检查用的`--quit-after`仍是显式退出工具。

`ddz-lab --play-model resnet|wp`仅覆盖本次启动，不自动保存配置；`ddz-bot-demo`、`evaluate-bot`和`simulate-continuous`支持同名参数。未准备所选权重时显示对应的`setup-agent --model`命令，运行中不自动联网，也不自动回退另一模型。

`--preview`仍可显式只读预览；`--record`启动只录像任务，`--continuous`等待模型和设备就绪后启动连续游戏，二者优先于默认预览。只录像也使用“停止并保存”结束。`--acceptance`仍作为命令行录像参数保留，界面不再提供验收复选框。

`profile.flow_room`仅保留格式兼容，读取和保存统一归为`当前`，旧取值不再限制运行。旧`--flow-room`参数继续接受任意字符串并忽略；软件始终从当前页面开始，不主动选择其他房间。洗牌、不洗牌及其他名称均不阻止有明确匹配按钮的大厅启动。游戏给出唯一明确切场目标及普通确认按钮时可自动确认；充值、购买、健康系统等仍暂停。入口不限玩法，出牌仍使用现有标准54张牌规则，不新增特殊玩法规则。

默认录像总额20 GiB，磁盘空闲低于2 GiB停止录像，不自动删除旧资料。
