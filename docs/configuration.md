# 配置与数据

数据目录依次选择：

1. 显式`--data-dir`参数。
2. `DDZ_DATA_DIR`环境变量。
3. 从源码运行时的工程`data`目录。
4. 安装版的`%LOCALAPPDATA%\DoudizhuLab`。

不根据终端当前目录猜测工程，也不将运行资料写入`site-packages`。其他平台存在XDG路径退路，但目前只声明Windows支持。

```powershell
uv run ddz-lab --data-dir .\data
uv run ddz-check --data-dir .\data devices
```

ADB路径以调用者明确指定和保存的配置为准；未配置时读取`ADB_PATH`，再查找PATH。没有作者电脑固定盘符依赖。所有设备命令必须指定序列号。

## 本机目录

| 目录／文件 | 用途 | 提交到Git |
| --- | --- | --- |
| `settings.json` | 第五版配置与当前标定 | 否 |
| `templates`、`markers`、`controls` | 牌点、标记和按钮模板 | 否 |
| `models`、`tools` | 已校验权重与视频服务器 | 否 |
| `sessions`、`runs` | 录像、观察、修订和任务账本 | 否 |
| `migration` | 本机迁移和验证记录 | 否 |

旧配置读取时补齐默认值，首次保存升级为第五版并保留`settings.v原版本.bak.json`。原有第四版字段与SQLite记录保持兼容；`profile.play_model`新增`resnet`、`wp`两种选择，缺少该字段时默认ResNet。示例配置不含真实设备路径或可执行的按钮标定。

启动自动后台加载所选本地模型，默认ResNet，唯一授权设备自动只读预览；加载和预览本身不授予自动输入。运行授权、动作和连续执行状态不跨重启保存。新配置默认严格模式、固定不叫不抢、始终不加倍、最多5局或30分钟；已有配置保留已保存的偏好。

“设置”管理目标设备、刷新设备、ADB路径、出牌模型、场次、连续策略、叫抢策略及任务上限。时长精确到秒，保存后用于下一次任务；准备、录制、暂停和保存期间相关字段只读。取消不改变配置，保存失败保留原值。空闲时保存新的模型选择会后台串行卸载旧模型、加载新模型；旧建议失效，加载期间不能开始任务。不清除已有模板、区域、按钮标定或叫抢阈值。

`ddz-lab --play-model resnet|wp`仅覆盖本次启动，不自动保存配置；`ddz-bot-demo`、`evaluate-bot`和`simulate-continuous`支持同名参数。未准备所选权重时显示对应的`setup-agent --model`命令，运行中不自动联网，也不自动回退另一模型。

`--preview`仍可显式只读预览；`--record`启动只录像任务，`--continuous`等待模型和设备就绪后启动连续游戏，二者优先于默认预览。只录像也使用“停止并保存”结束。`--acceptance`仍作为命令行录像参数保留，界面不再提供验收复选框。

`profile.flow_room`和`--flow-room`共用场次取值：`初级`、`中级`、`高级`或`当前`。新配置默认初级；“当前”表示从当前已识别的初、中、高级洗牌大厅开始，保留原有场次，不主动选择其他房间。明确指定场次时，大厅或切换提示必须与选择一致；目标不明确时暂停。

默认录像总额20 GiB，磁盘空闲低于2 GiB停止录像，不自动删除旧资料。
