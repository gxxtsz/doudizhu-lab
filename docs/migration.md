# 迁移至0.5版

项目名由`android-ddz-toolkit`改为`doudizhu-lab`，Python包由`ddz_device`改为`doudizhu_lab`。旧内部导入不兼容；命令`ddz-device`、`ddz-check`、`ddz-bot-demo`保留，新增`ddz-lab`和版本查询。

## 本次工作区整理

新工作区只包含可公开源码与被Git忽略的必需本机资源。原项目、旧环境、录像、独立标注、原始观察和失败批次保留在原位置，不覆盖、不删除。没有将旧`.venv`搬到新目录；新目录通过uv重新安装。

复制的本机资源包含当前第四版配置、牌点／标记／按钮模板、三份WP权重、叫抢权重、三份OCR权重及scrcpy-server，保留校验与来源。不复制日志、历史会话、调试截图、缓存、旧配置备份、IDE配置和YOLO权重。

原始资源SHA-256清单和模块映射保存在本机`data/migration`，不进入Git或发行包。公开克隆只得到源码，需要自行下载模型和标定模板。

## 代码与功能变化

- 领域契约、配置默认值与视觉实现分离；窗口组件、启动参数和运行协调分开。
- CPU模型子进程、快照资源和工具入口改用新包路径。
- 删除YOLO、全区域OCR和不参与实际流程的实验后端；保留模板、实用手牌OCR与流程OCR。
- 回放评测需显式`--scope`，不再内置某个开发会话的八局范围。旧本机范围清单留在忽略目录。
- 版本统一为0.5.0；第四版配置、JSON／SQLite字段及运行授权默认行为不改变。

旧会话可显式打开。历史引擎快照保持原包名、原哈希和锁文件；使用旧快照自己的工程重现，不批量替换其内容。新源码的重新分析不会冒充旧实时记录。

旧环境或脚本若依赖`ddz_device.*`，应按[架构](architecture.md)更新内部导入；不提供覆盖所有内部路径的兼容空壳。

## Git准备

新目录初始化本地`main`分支，无提交、无远程、无推送。发布前检查`git status --short`与构建产物，确认没有本机资源，再自行创建GitHub仓库。此轮未创建GitHub仓库、上传数据或发布软件包。
