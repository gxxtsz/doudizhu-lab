# 区域、模板与操作标定

模板依赖游戏布局和尺寸。默认区域是2400×1080经典牌桌的起点，不是通用适配保证。仓库不附游戏画面或原开发者设备模板。

## 区域与牌点

1. 保存稳定画面，冻结后切到区域标定模式；拖出手牌、底牌、自己出牌、左侧出牌、右侧出牌五区。
2. 在模板采集模式裁剪牌点，选择标签。普通牌保留重复张数，`SJ`为小王、`BJ`为大王。
3. 手牌、底牌、桌面小牌分别采集尺寸；三家已出牌共享桌面模板，自己的区域单独设置字号。
4. 覆盖选中上移、叠牌及大小王。模板裁剪避免带入头像、昵称、聊天泡或顶部记牌器。
5. 用不同来源的截图验证；模板来源和验证来源按整局隔离，不将机器预测导出为人工真值。

模板不全、遮挡或匹配不明确时显示无法确认。匹配分数不是概率或胜率。可选手牌OCR只替换字形分类，位置仍来自传统分割；底牌和桌面模板仍然必要。

## 标记与按钮

校准地主、行动提示、剩牌数、阶段和不出字样；“不抢”属于叫抢阶段，不能当作不出。确认自己、左侧、右侧的真实轮转后保存座位顺序。

出牌执行前完成手牌常态牌顶、选中上移量、出牌与不出按钮标定。第一次只验证同一张牌选中与取消，再单步执行。按钮必须真实可见且可用；模板采集和回放界面不会发送手机输入。

录制期间配置和模板只读；调整后开始新的会话，防止同局混用不同识别配置。
