# 模型与连续运行

出牌使用固定DouZero WP社区权重副本，地主、地主上家和地主下家分别编码；CPU子进程推理，不训练。对手未知牌只作为合并集合，不分配成两家的隐藏手牌。

叫抢使用固定Net2模型，只输入自己的17张牌。首叫、首次抢和回抢阈值分别为0.2、0.5、0.6；输出为未经本游戏校准的原始评分，不是胜率。始终不加倍。

## 模式

- **仅建议**：启动默认模式，不输入。
- **单步执行**：完成当前动作后等待。
- **自动执行**：负责当前局出牌，结算停止。
- **连续任务**：显式负责大厅、经典场次匹配、叫抢、不加倍、出牌和下一局。

点击“开始连续游戏”会自动准备视频记录与模型。正在截图预览或识别时，会先暂停预览，等当前画面任务结束后自动继续启动，无需重复点击；等待期间可用“立即停止 / 人工接管”取消。录像正在启动或收尾时，需等该操作结束后再启动连续任务。

```powershell
uv run --extra vision ddz-lab --continuous --continuous-policy balanced --bidding model --flow-room 当前
```

默认最多5局或30分钟；`--max-games`可显式设为1～30，`--time-limit`最多14400秒，时间到后打完当前局停止。初级、中级或当前场次需要用户明确选择；补币、充值及未知弹窗不自动处理。

## 推断优先与暂停

短暂缺失先收集新帧。有手牌守恒、计数、明确行动提示及唯一轮转的两帧证据时允许推断不出，证据跨越至少100毫秒。本人提交后的不出提示漏检另有严格的提交时间核对。推断不改原始观察，评测独立核对来源。

平衡模式在历史不完整但当前回合明确时可使用规则策略，棋力可能下降，并单独记录。按钮和选牌不根据猜测点击；手牌不确定、轮转矛盾、真实缺口、未知提交或健康系统阻断时暂停。

每次选牌后重新定位，提交前两帧核对选中多重集合，命令只提交一次。点击成功不等于游戏接受；手牌变化、自己的出牌和行动转换提供确认。普通确认窗口3秒，炸弹／王炸特效最多5秒。页面短暂漏识别在平衡模式下最多8秒等待证据，期间不重复点击。

立即停止会撤销后续输入，已经发出的单次命令记为在途，不能撤回。授权不跨重启或跨新任务恢复。

```powershell
uv run ddz-check simulate-continuous --runs 6 --policy balanced --bidding model --require-pass
uv run ddz-check evaluate-run .\data\runs\示例任务 --require-pass
```

模拟与真机分别标记。30局任务必须实际完成30局才能通过，不累计失败批次。当前实测限制见[验证状态](validation.md)。
